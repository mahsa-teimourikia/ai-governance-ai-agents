# AI Governance for Agents

A comprehensive curriculum for transitioning from AI model governance to Autonomous Agent governance.

## Quickstart

### Prerequisites
- Node.js >= 18
- Python 3.11+
- `uv` package manager

### Environment Setup

Run the following command to set up both the Python and Node.js environments:
```bash
make setup-contributor
```

### Running the Learning Hub locally

```bash
npm run dev
```

### Running Tests

```bash
make test
```
